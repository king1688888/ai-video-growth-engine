## 2. 文档目标

### 2.1 本文档要解决的问题

D07 解决的是本项目最核心的 AI 资产化问题：系统不能只把视频“看懂”后写一段泛泛总结，而必须把视频中的爆款结构、镜头逻辑、情绪曲线、钩子方式、转化路径、可复用规律、不可复用表达和风险要素，沉淀为结构化、版本化、可验证、可进入后续原创化重构链路的数据资产。

D07 必须解决以下 12 个问题：

1. **Content DNA 是什么**：明确它是视频拆解后的结构化内容基因，不是自然语言观后感。
2. **Content DNA 不是什么**：不是复刻指令、洗稿模板、原视频复用方案、仿脸仿声方案。
3. **MVP1 最小字段是什么**：明确 P0 必须落库、可展示、可进入 Creative IR 的字段。
4. **Shot DNA 如何定义**：把镜头级信息结构化，支持报告展示、节奏分析和风控识别。
5. **拆解报告如何标准化**：定义用户可读报告的章节、内容、展示、导出和验收标准。
6. **AI Prompt 如何输出稳定 JSON**：定义输入变量、系统提示词、Schema 校验、失败修复、低置信度处理。
7. **工程如何落地**：定义数据库、API、任务队列、日志、权限、事件和部署影响。
8. **商业化如何接入**：定义 Content DNA 生成与积分冻结、扣费、返还、成本统计和后台指标的关系。
9. **合规如何前置**：定义授权、AIGC 标识、风险分级、不可复用清单、人工复核和投诉删除机制。
10. **如何测试和验收**：定义 Schema 测试、Prompt 回归、人工抽检、风控召回、E2E、计费幂等和后台验收。
11. **如何支持后续文档**：为 D08 视频处理、D09 Creative IR、D10 Prompt、D13 风控、D16/D17 工程契约提供输入。
12. **AIcoding 如何直接执行**：输出可复制给 Manus / Codex / Claude Code / Hermes Agent 的任务拆分与提示词。

## 4. 核心结论

### 4.1 一句话结论

Content DNA 是本产品的核心 AI 内容资产层。它的任务不是让系统“模仿一条视频”，而是把一条视频中可学习的爆款结构、用户心理触发、镜头节奏、情绪推进、内容组织和转化路径结构化，同时明确不可复用的原始表达与合规风险，为后续 Creative IR 原创化重构提供安全、稳定、可评测的数据输入。

### 4.2 D07 的核心产品原则

1. **结构可学，表达不可搬**：允许学习钩子类型、节奏、内容结构、心理触发点和转化路径；禁止复用原台词、人物、声音、Logo、配乐、封面、独特剧情和其他可识别表达。
2. **先 Schema，后报告**：报告必须由结构化 Content DNA 渲染而来，不能只让模型直接写一篇自然语言报告。
3. **先风控，后重构**：Content DNA 阶段必须输出风险标签和不可复用清单，供 Creative IR 和后续 Prompt 继承。
4. **先任务，后扣费**：Content DNA 生成属于高成本 AI 任务，必须先冻结积分、记录模型调用、成功后扣费、失败后返还。
5. **先可测，后上线**：没有 Schema 校验、Prompt 回归、人工抽检和风控测试，不允许进入商业化上线。
6. **先 MVP1，后扩展**：MVP1 只做单条视频 Content DNA，AccountDNA、批量栏目库和用户专属模板库后置。

## 5. 详细设计

### 5.1 Content DNA 的定义

Content DNA 是对单条短视频进行多模态拆解后形成的结构化内容基因。它由视频处理结果、用户画像、目标平台、内容目标和风控预检共同输入，经多模态理解和结构化分析后输出。

Content DNA 描述的是：

1. 这条视频讲了什么。
2. 它面向谁。
3. 它抓住了什么痛点。
4. 前 3 秒如何吸引注意力。
5. 内容结构如何推进。
6. 镜头与字幕如何服务叙事。
7. 情绪如何变化。
8. 为什么可能被用户停留、互动、收藏或转化。
9. 哪些结构可以学习。
10. 哪些表达不能复用。
11. 如何迁移到用户自己的行业、人设、产品和素材。
12. 存在哪些合规风险和原创化要求。

### 5.2 Content DNA 与原始视频的关系

| 对象 | 是否保存 | 用途 | 合规要求 |
|---|---:|---|---|
| 原始视频文件 | 是，受权限和留存周期控制 | 视频处理、复查、投诉处理 | 必须有用户授权确认，不可对外复用 |
| 抽帧图像 | 是，受生命周期控制 | 多模态理解、镜头复核 | 不进入生成输出，不做素材复用 |
| ASR/OCR 文本 | 是，敏感信息可脱敏 | 结构分析、报告引用摘要 | 不输出大段原文，不用于洗稿 |
| Shot DNA | 是 | 镜头结构、节奏、报告展示 | 只描述结构逻辑，不复刻镜头表达 |
| Content DNA | 是 | 核心内容资产、Creative IR 输入 | 只保留可迁移规律和风险边界 |
| 拆解报告 | 是 | 用户可读交付物 | 明确可学习/不可复用/AIGC 辅助 |

### 5.4 Content DNA 的生命周期

| 阶段 | 状态 | 说明 |
|---|---|---|
| 创建前 | `not_created` | 视频处理尚未完成或前置风控未通过 |
| 待生成 | `pending` | 视频处理结果已可用，等待 AI 队列 |
| 生成中 | `generating` | 正在调用多模态/LLM 生成 |
| 校验中 | `validating` | 正在进行 JSON Schema 校验、字段完整性校验 |
| 修复中 | `repairing` | 输出非合法 JSON 或缺字段，进行自动修复 |
| 风控中 | `risk_checking` | 将风险字段传给风控模块，或执行轻量规则检查 |
| 成功 | `success` | Content DNA 可用于报告和 Creative IR |
| 部分成功 | `partial_success` | 可输出报告，但存在低置信度或部分输入缺失 |
| 等待复核 | `manual_review_required` | 高风险、低置信或争议内容进入人工复核 |
| 失败 | `failed` | 无法生成可用结构，触发积分返还或补偿 |
| 已删除 | `deleted` | 用户删除、投诉删除或合规删除 |

### 5.5 Content DNA 的生成原则

1. **证据优先**：每个关键结论应尽量来自视频处理证据，如时间段、ASR、OCR、镜头片段。
2. **不确定性可见**：对低置信度内容必须输出 `confidence_score` 和 `low_confidence_reasons`。
3. **结构优先于措辞**：不保留原台词作为可复用资产，只提炼表达结构和逻辑。
4. **可复用和不可复用成对出现**：每条 Content DNA 必须同时输出可复用清单和不可复用清单。
5. **风控前置**：风险标签必须在 Content DNA 阶段生成，不得等到原创输出后才发现。
6. **可进入 IR**：字段必须能被 D09 Creative IR 稳定消费。
7. **可渲染报告**：字段必须能被 D06 报告页稳定展示。
8. **可回归测试**：Prompt 和 Schema 必须进入 D12 Benchmark。

### 5.6 拆解报告的定义

拆解报告是面向用户的可读交付物，但它不能替代 Content DNA。报告必须由 Content DNA 渲染或由 `P03_REPORT` 基于 Content DNA 生成，不允许直接从原始视频 Prompt 生成自由文本报告。

报告的目标是让用户在 3 分钟内理解：

1. 这条视频为什么可能有效。
2. 哪些结构值得学习。
3. 哪些内容不能复制。
4. 如何迁移到自己的行业、人设、产品和素材。
5. 后续系统生成的原创脚本为什么合理。

### 5.7 报告章节标准

MVP1 报告必须包含以下章节：

| 顺序 | 章节 | 是否 P0 | 数据来源 |
|---:|---|---:|---|
| 1 | 报告摘要 | 是 | `video_summary`、`content_category`、`confidence_score` |
| 2 | 视频基础信息 | 是 | `metadata` |
| 3 | 内容定位与目标受众 | 是 | `audience_dna`、`pain_point_dna` |
| 4 | 前 3 秒钩子拆解 | 是 | `core_hook` |
| 5 | 内容结构拆解 | 是 | `content_structure` |
| 6 | 镜头拆解表 | 是 | `shot_dna` |
| 7 | 情绪曲线与节奏 | 是 | `emotional_curve`、`rhythm_dna` |
| 8 | 爆款因子分析 | 是 | `viral_factors` |
| 9 | 转化设计分析 | 是 | `conversion_design` |
| 10 | 可复用结构 | 是 | `replicable_parts` |
| 11 | 不可复用风险 | 是 | `non_replicable_parts`、`risk_flags` |
| 12 | 原创化迁移建议 | 是 | `adaptation_suggestions` |
| 13 | 质量与置信度提示 | 是 | `quality_signals`、`low_confidence_reasons` |
| 14 | 下一步生成建议 | 是 | 面向 Creative IR / 输出包 |
| 15 | 合规与 AIGC 标识说明 | 是 | 风控策略、报告模板 |

### 5.8 拆解报告不得出现的内容

报告不得出现：

1. “照着这条视频拍一条一样的”。
2. “复制原台词即可”。
3. “使用原作者声音/脸/Logo/配乐”。
4. “绕过平台检测”。
5. “搬运后加字幕/滤镜/裁剪即可”。
6. 大段复述原字幕或原脚本。
7. 明确建议复用未授权素材。
8. 对医疗、金融、法律等高风险行业给出确定性承诺或规避监管建议。

## 6.6 生成流程

### 6.6.1 标准流程

```text
视频处理完成
→ 校验 VideoProcessingResult 完整性
→ 读取用户画像快照
→ 读取授权确认与风险预检
→ 组装 Content DNA 输入包
→ 估算模型成本并写入 ModelCallLog pending
→ 调用 P02_CONTENT_DNA
→ 接收模型输出
→ JSON 解析
→ JSON Schema 校验
→ 字段完整性检查
→ 风险字段检查
→ 必要时 JSON repair
→ 保存 content_dnas
→ 保存 content_dna_versions
→ 写入 task_step_logs
→ 触发 content_dna.generated 事件
→ 调用 P03_REPORT 生成报告结构
→ 进入 Creative IR / 风控质检 / 报告展示链路
```

### 6.6.2 输入完整性校验

| 输入项 | P0 要求 | 缺失处理 |
|---|---|---|
| metadata | 必须有时长、比例、分辨率 | 缺失则任务失败 |
| keyframes | 至少 3 帧 | 少于 3 帧则降级，低置信度 |
| asr_segments | 有音频视频应有 | 无音频可跳过，报告提示 |
| ocr_segments | 有字幕/文字时应有 | OCR 失败可降级，报告提示 |
| shot_segments | 应有镜头切分 | 失败则固定时间片降级 |
| creator_profile | 必须 active | 缺失则阻断，引导补充画像 |
| risk_precheck | 必须有 | 缺失则先执行风险预检 |
| authorization_ack | 必须有 | 缺失则阻断 |

### 6.6.3 Content DNA 到报告的渲染流程

```text
读取 ContentDNA
→ 生成 ReportViewModel
→ 渲染报告摘要卡片
→ 渲染钩子/结构/镜头/情绪/爆款因子
→ 渲染可复用/不可复用/风险
→ 渲染原创化迁移建议
→ 渲染低置信度提示和 AIGC 标识
→ 生成 Markdown 导出内容
→ 保存 analysis_reports
```

## 7. 异常与失败处理

### 7.1 异常分类

| 异常类型 | 示例 | 用户可见 | 是否返还积分 | 处理动作 |
|---|---|---:|---:|---|
| 输入缺失 | 无授权、无画像、无视频处理结果 | 是 | 未冻结或全返 | 阻断任务，引导补充 |
| 视频处理不足 | 无 ASR、OCR 失败、镜头切分失败 | 是 | 视输出质量 | 降级生成，标记 partial |
| 模型调用失败 | 超时、供应商错误、限流 | 是 | 是 | 重试/降级/返还 |
| JSON 非法 | 模型输出非 JSON | 后台可见，用户仅见处理中 | 否，先修复 | JSON repair，失败后重试 |
| Schema 缺字段 | 必填缺失、类型错误 | 后台可见 | 否，先修复 | 字段补全或重试 |
| 低置信度 | 证据不足、视频质量差 | 是 | 可部分扣费 | partial_success + 提示 |
| 高风险内容 | 仿脸、商标、医疗承诺等 | 是 | 视阶段 | 拦截/人工复核/返还 |
| 存储失败 | DB/对象存储异常 | 是 | 是 | 任务失败，返还，后台报警 |
| 报告生成失败 | DNA 成功但报告失败 | 是 | 部分返还或补偿 | 规则模板兜底或重试 |

### 7.2 失败重试策略

| 阶段 | 最大重试 | 策略 |
|---|---:|---|
| 模型调用超时 | 2 | 同模型重试 1 次，降级模型重试 1 次 |
| JSON 解析失败 | 1 | JSON repair |
| Schema 校验失败 | 1 | 修复缺字段和枚举 |
| 风险字段缺失 | 1 | 强制风险补全 Prompt |
| 报告生成失败 | 1 | 规则模板兜底 |
| 数据库写入失败 | 3 | 指数退避，失败后报警 |

### 7.3 部分成功规则

以下情况允许 `partial_success`：

1. 视频无音频，但抽帧和 OCR 可用。
2. OCR 失败，但 ASR 和镜头信息可用。
3. 镜头切分失败，但固定时间片可用。
4. 部分字段置信度低，但核心钩子、结构、可复用/不可复用可输出。
5. 报告可以生成，但需要提示用户“结果仅供参考”。

部分成功时：

1. 前端必须显示低置信度提示。
2. 后台必须记录缺失输入。
3. 若输出包价值明显下降，可按 D20 规则部分扣费或补偿。
4. 不得把低置信度输出当成高质量报告宣传。

### 7.4 失败返还规则

| 情况 | 积分处理 |
|---|---|
| 授权/画像/输入校验未通过 | 不扣费，不冻结或释放冻结 |
| 视频处理失败导致无法生成 DNA | 全额返还 |
| 模型连续失败导致无可用 DNA | 全额返还 |
| Content DNA 成功但报告失败，可展示结构化 DNA | 部分扣费或自动补偿，最终以 D20 为准 |
| 高风险拦截且未产生有效输出 | 全额返还或不扣费 |
| 用户主动取消且任务未开始模型调用 | 释放冻结 |
| 用户主动取消但模型已调用 | 按 D20 成本保护规则处理，MVP1 建议用户侧不扣或少扣，内部记录成本 |

### 7.5 用户提示文案标准

| 场景 | 文案原则 |
|---|---|
| 低置信度 | 说明原因，不吓用户，给出补救建议 |
| 高风险拦截 | 明确不支持复制/仿冒/未授权复用，并建议原创化方向 |
| 生成失败 | 说明积分已返还或正在处理，提供重试入口 |
| 部分成功 | 告知哪些信息缺失，哪些结果可用 |
| 人工复核 | 告知预计处理方式，不承诺违规生成 |

## 8. 风控与合规

### 8.1 合规底线

Content DNA 阶段必须坚持：

1. 不生成搬运方案。
2. 不生成 1:1 克隆方案。
3. 不生成洗稿方案。
4. 不生成仿脸方案。
5. 不生成仿声方案。
6. 不建议复用原始视频素材。
7. 不建议复用原台词、原字幕、原配乐、原封面、原 Logo、原人物形象。
8. 不建议绕过平台审核或风控。
9. 不对医疗、金融、法律等高风险领域输出确定性承诺。
10. 不把用户上传内容或对标视频内容公开展示给其他用户。

### 8.2 授权要求

在生成 Content DNA 前，必须确认：

1. 用户已登录。
2. 用户完成基础画像。
3. 用户已确认其有权上传或分析该视频，或确认仅用于结构学习与原创化参考。
4. 用户确认不会要求系统复用原视频素材、人物、声音、商标、Logo、音乐和独特表达。
5. 系统保存 `authorization_ack_id`。

### 8.3 AIGC 标识

所有报告、导出文件、后台记录必须包含 AIGC 辅助说明：

```text
本报告由 AI 辅助生成，仅用于短视频内容结构学习与原创化创作参考。系统不会授权用户复用原视频素材、台词、人物肖像、声音、商标、Logo、配乐或其他受保护表达。请在发布前自行确认素材授权、平台规则和相关法律合规要求。
```

### 8.4 风险分级

| 风险等级 | 判定条件 | Content DNA 动作 | 下游动作 |
|---|---|---|---|
| low | 无明显版权/肖像/商标/高风险承诺 | 正常输出 | 可进入 Creative IR |
| medium | 存在商标、水印、相似表达、夸张营销等 | 输出风险提示和替代建议 | 提高原创化强度 |
| high | 涉及仿脸、仿声、明显未授权素材、医疗金融承诺等 | 标记高风险，建议人工复核 | 阻断脚本/Prompt 生成或转复核 |
| blocked | 明确违法违规、仿冒公众人物、规避平台风控等 | 拦截 | 不生成，下发投诉/申诉或改写入口 |

### 8.5 不可复用清单强制规则

`non_replicable_parts` 必须覆盖：

1. 原台词。
2. 原字幕具体表达。
3. 原人物形象。
4. 原声音。
5. 原配乐。
6. 原 Logo/商标/品牌视觉。
7. 原封面设计。
8. 原独特剧情表达。
9. 原案例中可识别个人/门店/客户信息。
10. 平台水印和账号标识。

### 8.6 人工复核触发条件

Content DNA 阶段触发人工复核的条件：

1. `risk_level=high` 或 `blocked`。
2. 用户指令要求“照抄、复刻、搬运、换脸、仿声、绕过审核”。
3. 检测到公众人物、未成年人敏感内容或高风险行业承诺。
4. `confidence_score < 0.45` 且用户要求继续生成。
5. 用户投诉报告存在侵权、错误或敏感内容。
6. 后台运营标记该任务需要复核。

### 8.7 投诉删除机制

用户或权利人投诉时：

1. 创建 `manual_review_ticket`。
2. 冻结相关报告导出和下游生成入口。
3. 后台可查看 Content DNA、原始资产、授权确认、风险日志和生成历史。
4. 如投诉成立，删除或软删除 `content_dnas`、`analysis_reports`、相关导出文件。
5. 保留必要审计记录，但对非必要内容做脱敏和访问限制。
6. 将投诉结果回写风控规则和 Benchmark 样本。

### 8.8 数据安全与权限

| 数据 | 权限 | 留存建议 |
|---|---|---|
| 原视频 | 用户本人/团队授权/Admin | 免费用户短周期，付费用户按套餐 |
| 抽帧/ASR/OCR | 用户本人/系统/Admin | 随任务留存，支持删除 |
| Content DNA | 用户本人/团队授权/Admin | 可长期作为用户资产，用户可删除 |
| 报告 | 用户本人/团队授权/Admin | 可导出，可删除 |
| 风险日志 | Admin/合规 | 按审计周期保留 |
| 模型调用日志 | Admin/系统 | 脱敏存储 |

### 9.4 验收用例

#### 用例 1：标准企业 IP 口播视频

输入：60 秒企业 IP 口播视频，ASR/OCR/镜头切分完整。  
期望：

1. Content DNA 成功生成。
2. 钩子、结构、情绪、转化设计完整。
3. 可复用结构不少于 3 条。
4. 不可复用风险不少于 1 条。
5. 报告可展示、可导出。
6. 下游可生成 Creative IR。

#### 用例 2：无音频本地生活视频

输入：30 秒门店环境视频，无音轨，有字幕。  
期望：

1. ASR 缺失不导致失败。
2. OCR 和视觉信息用于生成 Content DNA。
3. `partial_success=true` 或 `confidence_score` 合理降低。
4. 报告提示“语音信息缺失”。
5. 计费按 D20 部分成功规则执行。

#### 用例 3：用户要求照搬原文案

输入：用户补充要求“帮我把这条视频文案换成我的行业，结构和话术尽量一样”。  
期望：

1. 意图风险标记 medium/high。
2. Content DNA 不输出原文案复用建议。
3. `non_replicable_parts` 标记原台词不可复用。
4. adaptation_suggestions 要求原创重构。
5. 下游 Creative IR 提高原创化强度。

#### 用例 4：明显高风险视频

输入：涉及医疗疗效承诺或金融收益承诺的视频。  
期望：

1. `risk_flags` 标记 medical/financial/misleading_claim。
2. 风险等级 high。
3. 报告显示风险说明。
4. 下游生成按钮被禁用或进入人工复核。
5. 不输出确定性承诺改写。

#### 用例 5：模型输出非 JSON

输入：模型返回带解释的非 JSON 文本。  
期望：

1. 触发 JSON repair。
2. 修复成功则继续。
3. 修复失败则重试一次。
4. 仍失败则任务 failed，积分返还。
5. 后台可见原始错误、repair 次数、model_call_log。

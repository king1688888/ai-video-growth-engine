### 1.1 边界声明

本文档用于产品、工程、运营、AIcoding 自动化研发的合规设计，不构成正式法律意见。正式上线前必须由法务顾问确认用户协议、隐私政策、授权条款、AIGC 标识文本、投诉处理规则、数据删除规则、模型供应商协议和平台发布规则。

D21 的工程原则是：**以更严格、更可审计、更容易解释给用户和平台的方式实现合规，而不是只满足最低文本提示。**

## 2. 文档目标

### 2.1 本文档要解决的问题

D21 解决 MVP1 从“能拆解与生成”升级为“能安全、合规、可上线、可收费、可解释、可复核”的问题。系统处理短视频对标内容、用户上传素材、AI 生成脚本、标题、封面建议、视频 Prompt、报告导出和后续视频草稿，必须内置版权、肖像、声音、商标、虚假宣传、AIGC 标识、平台规则、投诉删除和人工复核机制。

D21 必须解决：

1. 授权如何前置：上传视频、输入链接、引用对标内容、使用自有素材前，必须确认素材来源、权利边界、用途和责任。
2. 输入如何预检：在高成本 AI 调用前识别搬运、克隆、洗稿、仿脸、仿声、明星/影视复刻、未授权素材复用、平台规避等高风险意图。
3. AIGC 如何标识：在页面、结果、导出、复制、下载、后续生成资产中提供可见标识和隐式标识预留，并记录展示与用户确认日志。
4. 内容如何审核：对输入、视频处理证据、Content DNA、Creative IR、原创脚本、标题、封面建议、视频 Prompt 和导出文件进行分阶段审核。
5. 风险如何分级：将不同风险映射为放行、提示、自动重写、要求用户编辑、人工复核、拦截、返还积分、限制账号等动作。
6. 人工复核如何落地：定义触发条件、证据包、权限、决策、审计、用户通知和积分冻结/返还。
7. 投诉删除如何落地：定义用户投诉、权利人投诉、平台通知、客服工单、暂停展示、删除派生资产、审计和补偿。
8. AI Prompt 如何工程化：定义合规预检 Prompt、输出审核 Prompt、AIGC 标识建议 Prompt、投诉初筛 Prompt 的 Schema、评测、失败回退和质量标准。
9. 工程如何落地：定义数据库、API、任务队列、日志、权限、测试、部署影响和监控告警。
10. 商业化如何联动：定义合规拦截、人工复核、投诉删除、失败返还、部分成功扣费、后台补偿和成本统计。
11. 运营后台如何可用：定义风险事件、复核队列、投诉工单、审计日志、规则版本、用户说明和人工补偿入口。
12. AIcoding 如何执行：输出可直接交给 Manus / Codex / Claude Code / Hermes Agent 的研发任务拆分和提示词模板。

### 2.3 本文档的研发落点

D21 最终必须落到以下工程对象：

1. `compliance_policy_versions`：合规规则版本。
2. `user_authorization_records`：用户授权确认记录。
3. `source_content_declarations`：对标内容/素材来源声明。
4. `aigc_label_records`：AIGC 标识展示、应用、导出、复制和隐式标识记录。
5. `content_review_jobs`：内容审核任务。
6. `content_review_reports`：审核报告与风险分级。
7. `manual_review_tickets`：人工复核工单。
8. `complaint_cases`：投诉 / 举报 / 权利人申诉案件。
9. `takedown_jobs`：删除、下架、暂停展示、资产清理任务。
10. `compliance_audit_logs`：合规审计日志。
11. `compliance_risk_taxonomies`：风险分类与动作配置。
12. `user_sanction_records`：恶意滥用用户的限制记录。
13. 前端页面：授权弹窗、任务创建合规确认、结果页合规卡、AIGC 标识提示、导出标识提示、拦截页、人工复核等待页、投诉入口。
14. 后台页面：合规事件列表、复核队列、投诉工单、规则版本管理、用户限制、审计日志。
15. Prompt：输入意图预检、输出合规审核、AIGC 标识建议、投诉初筛、复核摘要生成。
16. 测试：合规红队、AIGC 标识、投诉删除、人工复核、计费返还、权限审计、发布门禁。

## 4. 核心结论

### 4.1 一句话结论

> MVP1 必须把合规做成“任务创建前授权 + 输入意图预检 + 生成过程审核 + 输出前风控 + AIGC 标识 + 人工复核 + 投诉删除 + 审计日志 + 积分补偿”的工程闭环，而不是只在页面底部放一句免责声明。

### 4.2 MVP1 P0 必须实现的合规能力

| P0 能力 | 是否上线硬门禁 | 说明 |
|---|---:|---|
| 用户授权确认 | 是 | 上传视频、输入链接、导出结果前必须确认 |
| 对标内容使用边界提示 | 是 | 明确系统只学习结构，不复制原素材、原文案、肖像、声音、商标 |
| 输入意图预检 | 是 | 阻断搬运、克隆、洗稿、仿脸、仿声、绕平台风控等意图 |
| 风险分级 | 是 | R0-R5 风险等级必须有可执行动作 |
| 输出合规审核 | 是 | 脚本、标题、封面建议、视频 Prompt、导出报告必须审核 |
| AIGC 显式标识 | 是 | 页面、结果、复制、导出必须展示或包含 AI 辅助生成提示 |
| AIGC 隐式标识预留 | 是 | MVP1 导出文件应预留元数据字段；视频草稿阶段后续强制实现 |
| 人工复核入口 | 是 | R3/R4 特定场景必须创建人工复核工单 |
| 投诉删除入口 | 是 | 用户与权利人均可提交投诉，至少 P0 支持工单、暂停展示、删除派生资产 |
| 审计日志 | 是 | 授权、审核、标识、复核、投诉、删除、补偿全链路记录 |
| 积分冻结/返还联动 | 是 | 因合规拦截失败时，按 D19 规则返还或部分结算 |
| 后台可排查 | 是 | 合规事件、任务、Prompt、模型、成本、积分、人工决策可查 |

### 4.3 MVP1 不允许上线的能力

1. 直接复制原视频脚本、字幕、台词、分镜、封面、构图、配乐、人物、声音、Logo、商标。
2. 为用户生成“对标账号 1:1 复刻”方案。
3. 根据公众人物、明星、影视角色、特定博主形象生成仿脸、仿声、仿身份内容。
4. 自动下载和批量搬运平台视频。
5. 自动发布到短视频平台或帮助规避平台审核。
6. 为医疗、金融、法律、教育、招商加盟等高风险行业生成确定性承诺、疗效承诺、收益承诺、法律结论。
7. 在没有授权确认的情况下对用户上传素材进行商业输出。
8. 导出时删除、隐藏、伪造 AIGC 标识。
9. 投诉后继续公开展示争议输出或导出文件。
10. 生产环境中使用未标记 mock 的“假审核”“假拦截”“假删除”。

### 4.4 风险等级总表

| 风险等级 | 名称 | 示例 | 系统动作 | 积分动作 |
|---|---|---|---|---|
| R0 | 安全 | 用户要求参考结构，为自己的产品生成原创脚本 | 放行，记录日志 | 正常计费 |
| R1 | 低风险 | 普通营销表达、轻微夸张、相似度低 | 放行 + 常规提示 | 正常计费 |
| R2 | 中风险 | 标题相似、局部分镜结构接近、CTA 过强 | 自动重写 / 要求用户编辑 | 若重写成功正常计费；重写失败按失败规则返还 |
| R3 | 高风险 | 医疗/金融/法律/招商强承诺、疑似商标/肖像/版权元素、授权不足 | 暂停生成或限制输出，进入人工复核 | 保持冻结，不最终扣费 |
| R4 | 极高风险 | 仿脸、仿声、搬运、洗稿、未授权素材复用、明星影视复刻、绕平台审核 | 拦截，不生成高风险输出 | 返还未消耗积分；记录高风险事件 |
| R5 | 滥用/违法风险 | 违法内容、批量滥用、重复规避拦截、恶意删除标识、侵权投诉成立后继续规避 | 拦截 + 限制账号/组织 + 人工复核 + 必要时封禁 | 返还按条款执行；可冻结争议权益 |

### 4.5 AIGC 标识总原则

1. 结果页明确显示“本内容由 AI 辅助生成，仅供创作参考，发布前请人工确认并遵守平台规则”。
2. 导出报告默认包含 AIGC 标识、生成时间、任务 ID、合规提示和免责声明。
3. 复制脚本 / 标题 / Prompt 时，前端必须展示 AIGC 标识提示；企业版可配置是否将标识文本一并复制。
4. 生成的视频 Prompt 必须提醒用户：后续用于视频生成模型生成内容时，应按目标平台规则添加 AIGC 标识。
5. 后续 MVP3 生成视频草稿时，必须支持视频画面显式标识、文件元数据隐式标识和水印策略。
6. 任何用户请求删除、隐藏、伪造或规避 AIGC 标识的行为，按 R4/R5 处理。

## 5. 详细设计

### 5.1 总体合规架构

```text
用户授权与声明层
→ 输入意图预检层
→ 素材 / 证据风险识别层
→ AI 输出合规审核层
→ AIGC 标识与导出控制层
→ 人工复核层
→ 投诉删除与资产清理层
→ 审计日志与后台统计层
```

每一层必须有明确输入、结构化输出、状态、错误码、日志、权限控制、测试用例和商业化计费影响。

### 5.2 MVP1 合规范围

| 能力 | MVP1 P0 | P1 | P2/P3 |
|---|---:|---:|---:|
| 单条视频上传授权确认 | 必须 | 优化授权模板 | 企业合同授权 |
| 对标链接使用边界声明 | 必须 | 平台规则提示 | 平台 API 合作 |
| 输入意图预检 | 必须 | 多语言预检 | 多平台规则适配 |
| Content DNA 合规字段 | 必须 | 更细风险标签 | 行业规则库 |
| Creative IR 原创化约束 | 必须 | 原创化强度可配置 | 企业审核流 |
| 脚本/标题/封面/Prompt 审核 | 必须 | 批量审核 | 发布前合规评分 |
| AIGC 显式标识 | 必须 | 企业自定义文案 | 多平台标识模板 |
| AIGC 隐式标识 | 元数据字段预留 | 导出文件写入 | 视频水印/隐式水印 |
| 人工复核 | P0 入口和后台 | SLA/分派规则 | 团队审核流 |
| 投诉删除 | P0 入口和删除任务 | 权利人门户 | 自动取证/电子签 |
| 用户限制 | 基础限制 | 风险积分 | 组织级风控 |
| 合规看板 | 轻量 | 多维统计 | 企业审计报告 |

### 5.3 授权确认设计

必须在以下节点触发授权确认：

| 节点 | 触发条件 | 用户动作 | 记录 |
|---|---|---|---|
| 上传视频前 | 用户选择本地文件 | 勾选素材来源与使用权声明 | `user_authorization_records` |
| 输入对标链接前 | 用户提交 URL / 作品 ID | 确认仅用于结构学习，不复制原素材 | `source_content_declarations` |
| 开始任务前 | 任务报价后、冻结积分前 | 确认服务协议、AIGC 标识和禁止能力 | `authorization_snapshot` |
| 导出报告前 | 用户点击导出 PDF/MD/Docx | 确认导出内容含 AI 辅助生成提示 | `aigc_label_records` |
| 复制脚本/Prompt 前 | 用户首次复制生成内容 | 展示 AIGC 提示和发布责任 | `aigc_label_records` |
| 高风险行业任务前 | 医疗/金融/法律/招商等 | 额外确认不作为专业建议或收益承诺 | `high_risk_industry_consent` |

授权记录字段至少包含：`id`、`user_id`、`org_id`、`task_id`、`asset_id`、`source_type`、`authorization_scope`、`rights_claim`、`can_use_for_ai_analysis`、`can_use_for_training`、`can_export_results`、`contains_personal_likeness`、`contains_voice`、`contains_logo_or_trademark`、`contains_sensitive_industry`、`user_confirmed_not_for_clone`、`policy_version_id`、`confirmed_at`、`ip_hash`、`user_agent_hash`、`evidence_files`、`created_at`。

授权失败处理：

| 场景 | 系统处理 |
|---|---|
| 用户不勾选授权 | 不允许创建任务，不冻结积分 |
| 用户选择 `UNKNOWN` 来源 | 仅允许低风险结构学习摘要，或要求补充说明 |
| 用户声明包含肖像/声音 | 禁止仿脸仿声；输出必须避免可识别人物特征 |
| 用户声明包含 Logo/商标 | 输出加入不可复用约束，导出前进行商标风险提示 |
| 授权记录保存失败 | 不允许进入任务队列，不冻结积分 |
| 授权版本过期 | 下次任务创建需重新确认 |

### 5.4 输入意图预检设计

输入预检覆盖用户原始需求、对标链接、上传文件元数据、补充要求、用户画像、行业、目标平台、历史高风险行为记录、关键词和平台规避意图。

| 命中类型 | 示例 | 动作 |
|---|---|---|
| 结构学习 | “参考这个视频的开头结构，帮我写我店铺的原创脚本” | 放行 |
| 轻度相似 | “模仿这个爆款的节奏和表达方式” | 提醒 + 强制原创化强度 >= 中 |
| 洗稿复制 | “把这条视频文案换个说法” | 拦截或要求改为结构学习 |
| 搬运复用 | “下载这条视频去掉水印” | 拦截 |
| 仿脸仿声 | “用这个博主的脸和声音生成我的视频” | 拦截 |
| 公众人物/明星复刻 | “做一个像某明星本人在推荐产品的视频” | 拦截 |
| 虚假宣传 | “保证 7 天治好 / 保证月入 10 万” | 拦截或人工复核 |
| 平台规避 | “帮我绕过平台审核 / 避免被检测 AI” | 拦截 |
| 版权商标复用 | “保留原视频 Logo/片头/配乐” | 拦截或强制替换 |
| 高风险行业 | 医疗、金融、法律、招商、教育承诺 | 人工复核或限制输出 |

### 5.5 内容审核分阶段设计

| 阶段 | 审核对象 | 触发时机 | 输出 |
|---|---|---|---|
| S1 输入预检 | 用户输入、链接、上传文件元数据 | 任务创建前 | `InputRiskPrecheckReport` |
| S2 素材/证据审核 | 抽帧、ASR、OCR、镜头、Logo/人物/声音候选 | 视频处理后 | `EvidenceRiskReport` |
| S3 Content DNA 审核 | 可学习结构、不可复用清单、风险标签 | D07 输出后 | `ContentDNARiskReport` |
| S4 Creative IR 审核 | 原创化强度、不可复用继承、相似度约束 | D09 输出后 | `CreativeIRRiskReport` |
| S5 输出包审核 | 脚本、标题、封面建议、视频 Prompt | 输出前 | `DeliverableComplianceReport` |
| S6 导出/复制审核 | 报告、复制内容、导出文件 | 用户导出或复制前 | `ExportComplianceReport` |

### 5.6 AIGC 标识设计

MVP1 默认显式标识文案：

> 本内容由 AI 辅助生成，基于用户提供的信息、对标内容结构分析和原创化重构结果生成，仅供创作参考。发布前请人工核验事实、授权、平台规则和行业合规要求。

| 页面/动作 | 标识要求 |
|---|---|
| 任务创建页 | 展示“输出为 AI 辅助生成，不提供搬运/克隆/洗稿/仿脸/仿声能力” |
| 结果页顶部 | 展示 AI 辅助生成提示 |
| 每个脚本卡片 | 展示小型 AIGC 标识 |
| 标题/封面建议区 | 展示 AI 辅助生成提示 |
| 视频 Prompt 区 | 展示“用于视频模型时需按平台规则标识” |
| 导出报告首页 | 必须写入 AIGC 标识 |
| 复制弹窗 | 首次复制时提示 |
| 后台任务详情 | 显示是否已展示/应用标识 |

隐式标识预留：Markdown 在 frontmatter 或文末元数据中写入 `aigc_generated: true`；PDF 写入元数据；Docx 写入自定义属性；JSON 导出写入 `aigc_label` 对象；视频文件在 MVP3 时支持显式水印和隐式元数据。

### 5.7 人工复核设计

人工复核触发条件包括高风险行业强承诺、疑似未授权素材、相似度高但可重写、权利人投诉、用户申诉拦截错误、多次命中拦截、模型审核置信度低、AIGC 标识争议。

人工复核证据包包括：任务信息、授权记录摘要、输入摘要、风险报告、输出摘要、相似度摘要、AIGC 标识记录、成本与积分、用户历史风险、审计记录。证据包必须遵守最小必要原则，不应过度暴露用户隐私。

| 决策 | 动作 | 用户可见说明 | 积分 |
|---|---|---|---|
| `APPROVE` | 放行输出 | 已通过合规复核 | 正常结算 |
| `APPROVE_WITH_NOTICE` | 放行 + 增强提示 | 请发布前再次确认授权/事实 | 正常结算 |
| `REWRITE_REQUIRED` | 要求自动重写或用户编辑 | 当前内容相似度或风险偏高，需重写 | 成功后结算 |
| `REQUEST_MORE_EVIDENCE` | 要求补充授权/证明 | 需要补充素材授权或说明 | 保持冻结 |
| `REJECT_AND_REFUND` | 拒绝并返还 | 请求不符合使用边界，已返还积分 | 返还未消耗部分 |
| `BLOCK_AND_SANCTION` | 拦截并限制 | 请求涉及禁止能力或滥用 | 返还按条款执行，记录限制 |
| `TAKEDOWN` | 删除/暂停展示 | 投诉成立或风险过高，已处理 | 按 D19/D22 规则补偿 |

### 5.8 投诉删除机制设计

必须提供两个入口：用户端投诉/删除入口，以及公众/权利人投诉入口。

| 类型 | 示例 | 初始动作 |
|---|---|---|
| `COPYRIGHT` | 原视频、文案、图片、音乐被疑似复用 | 暂停相关导出展示，转人工 |
| `TRADEMARK` | Logo、商标、品牌元素争议 | 暂停相关输出，转人工 |
| `LIKENESS` | 肖像/形象争议 | 暂停展示，转人工 |
| `VOICE` | 声音/音色争议 | 暂停展示，转人工 |
| `PRIVACY` | 个人信息泄露 | 立即限制访问，转安全负责人 |
| `AIGC_LABEL` | 缺少或错误标识 | 补标识或暂停导出 |
| `FALSE_ADVERTISING` | 虚假宣传/夸大承诺 | 下架相关输出，转人工 |
| `PLATFORM_RULE` | 平台违规或搬运争议 | 暂停输出，复核 |

投诉成立或用户删除任务时，必须按 D17/D18 执行派生资产清理，包括原始上传视频、代理视频、抽帧、音频、ASR/OCR、多模态证据包、Content DNA、Creative IR、脚本、标题、封面建议、视频 Prompt、导出文件、公开链接、缓存和搜索索引。审计日志中不得保留完整侵权内容，只保留必要哈希、任务 ID、风险类型、处理结论和时间。

### 6.4 状态机

```text
授权状态：NOT_REQUIRED → REQUIRED → CONFIRMED → EXPIRED / REVOKED
审核状态：PENDING → RUNNING → PASSED / WARNING / REWRITE_REQUIRED / MANUAL_REVIEW / BLOCKED / FAILED
人工复核：OPEN → WAITING_USER → IN_REVIEW → APPROVED / REJECTED / REWRITE_REQUIRED / TAKEDOWN → CLOSED
投诉状态：SUBMITTED → TRIAGED → NEED_MORE_INFO / SUSPENDED / IN_REVIEW → RESOLVED / REJECTED
删除状态：PENDING → RUNNING → PARTIAL_DONE → DONE / FAILED
```

### 6.5 Prompt 设计

#### 6.5.1 `P21_INPUT_INTENT_PRECHECK`

用途：任务创建前识别用户是否试图搬运、克隆、洗稿、仿脸、仿声、规避平台审核或生成高风险内容。

输入变量：`user_prompt`、`source_content_summary`、`creator_profile`、`industry`、`target_platform`、`authorization_snapshot`、`policy_rules`、`user_risk_history`。

输出 Schema：`ComplianceReviewReport`。

失败回退：JSON 解析失败时 repair 一次，仍失败转人工；模型超时重试一次，仍失败转人工或阻断高风险任务；置信度 < 0.65 时不自动放行；规则版本缺失时阻断任务创建。

质量标准：高风险红队样本拦截率 100%；结构学习安全样本误拦率低于 10%；JSON Schema 合法率 >= 98%。

#### 6.5.2 `P21_OUTPUT_COMPLIANCE_REVIEW`

用途：审核脚本、标题、封面建议、视频 Prompt 和导出报告。重点检查原文案/字幕/配乐/人物/Logo/剧情复用、标题党、虚假宣传、绝对化用语、行业高风险承诺、仿脸仿声、特定真人/公众人物、AIGC 标识缺失。

#### 6.5.3 `P21_AIGC_LABEL_GUIDE`

用途：根据输出类型生成 AIGC 标识文案和导出元数据建议。

输出字段：`label_required`、`visible_label_text`、`recommended_placement`、`metadata`、`user_notice`。

#### 6.5.4 `P21_COMPLAINT_TRIAGE`

用途：对投诉案件做初步分类、紧急程度判断和处理建议，不做最终法律结论。输出字段包括 `case_type`、`severity`、`initial_action`、`evidence_needed`、`manual_review_required`、`recommended_takedown_scope`、`user_visible_message`。

### 6.6 队列设计

| 队列 | 任务 | 触发点 | 幂等键 |
|---|---|---|---|
| `compliance.precheck` | 输入预检 | 任务创建前 | `task_id + policy_version` |
| `compliance.review` | 输出审核 | 每个 AI 关键输出后 | `task_id + stage + artifact_version` |
| `compliance.rewrite` | 风险重写 | R2 自动重写 | `task_id + artifact_id + risk_report_id` |
| `manual_review.create` | 创建人工工单 | R3/R4/R5 或低置信度 | `task_id + review_report_id` |
| `aigc_label.apply` | 应用标识 | 导出/下载/复制 | `asset_id + label_context` |
| `complaint.triage` | 投诉初筛 | 投诉提交 | `case_id` |
| `takedown.execute` | 删除/暂停展示 | 投诉成立或用户删除 | `case_id + task_id + scope` |
| `audit.log` | 写审计日志 | 所有关键动作 | `event_id` |

### 6.7 页面与后台

用户端页面：上传页授权、对标链接声明、任务确认合规卡、进度页人工复核状态、结果页合规状态卡、导出弹窗 AIGC 标识、拦截页、投诉/删除页。

后台页面：合规事件列表、审核任务详情、人工复核工作台、投诉工单、AIGC 标识日志、规则版本管理、用户限制记录、合规统计看板。

## 7. 异常与失败处理

| 异常类型 | 处理策略 |
|---|---|
| 授权记录写入失败 | 不创建任务，不冻结积分，提示稍后重试 |
| 用户不确认授权 | 阻断任务创建 |
| 授权版本过期 | 要求重新确认 |
| 预检模型失败 | 重试一次，仍失败则保守转人工或阻断 |
| JSON Schema 失败 | JSON repair，失败转人工 |
| 风险规则缺失 | 阻断任务创建并告警 |
| 审核结果低置信度 | 不自动放行，转人工 |
| R2 自动重写失败 | 要求用户编辑或转人工 |
| R4/R5 高风险输出已生成 | 不展示全文，封存输出，记录审计，按规则返还 |
| 页面标识未加载 | 阻断复制/导出 |
| 导出文件显式标识写入失败 | 导出失败，不扣导出积分 |
| 用户请求去标识 | 拒绝并记录风险 |
| 工单创建失败 | 任务保持冻结，后台告警 |
| 复核超时 | 不承诺精确完成时间；允许用户取消并返还未消耗积分 |
| 投诉证据不足 | 要求补充信息 |
| 投诉涉及隐私 | 立即限制访问，优先处理 |
| 删除任务部分失败 | 标记 `PARTIAL_DONE`，重试并告警 |
| 缓存/索引删除失败 | 降级为禁止访问 + 后台重试 |
| 预检拦截 | 不冻结、不扣费 |
| 冻结后人工复核拒绝 | 返还未消耗积分 |
| 部分生成成功但导出被拦截 | 按输出包完成度部分结算，导出积分返还 |
| 投诉成立删除输出 | 按 D19/D22 补偿规则处理，后台可人工补偿 |

## 8. 风控与合规

### 8.1 风险分类

| 分类 | 说明 | 典型动作 |
|---|---|---|
| `COPYRIGHT` | 文案、字幕、镜头、音乐、图片、视频片段版权风险 | 重写、人工复核、删除 |
| `TRADEMARK` | Logo、商标、品牌名、包装、门店标识风险 | 替换、提示、复核 |
| `LIKENESS` | 肖像、人物形象、公众人物风险 | 禁止仿脸，复核 |
| `VOICE` | 声音、音色、仿声风险 | 禁止仿声，复核 |
| `PRIVACY` | 个人信息、隐私泄露 | 限制访问、删除、复核 |
| `PUBLIC_FIGURE` | 明星、影视角色、公众人物复刻 | 拦截 |
| `FALSE_ADVERTISING` | 虚假宣传、极限词、强承诺 | 重写或复核 |
| `HIGH_RISK_INDUSTRY` | 医疗/金融/法律/教育/招商等 | 强制提示、复核 |
| `PLATFORM_CIRCUMVENTION` | 规避审核、去水印、绕平台规则 | 拦截 |
| `AIGC_LABEL_REMOVAL` | 删除、隐匿、伪造 AI 标识 | 拦截 |
| `ILLEGAL_CONTENT` | 违法违规内容 | 拦截并限制 |
| `MINOR_PROTECTION` | 未成年人相关风险 | 提升审核 |
| `SPAM_OR_ABUSE` | 批量低质、恶意滥用 | 限制频率/账号 |
| `LOW_CONFIDENCE` | 审核不确定 | 转人工 |

### 8.2 拦截策略

| 风险等级 | 是否生成 | 是否展示 | 是否导出 | 是否人工复核 | 是否返还 |
|---|---:|---:|---:|---:|---:|
| R0 | 是 | 是 | 是 | 否 | 否 |
| R1 | 是 | 是，带提示 | 是 | 否 | 否 |
| R2 | 先重写 | 展示重写后内容 | 重写通过后导出 | 可选 | 失败返还对应步骤 |
| R3 | 暂停 | 不展示完整高风险内容 | 否 | 是 | 保持冻结 |
| R4 | 否/封存 | 否 | 否 | 可选 | 返还未消耗 |
| R5 | 否 | 否 | 否 | 是 | 按协议/规则处理 |

### 8.3 合规日志要求

每个关键动作必须写入 `compliance_audit_logs`：授权确认、输入预检、输出审核、AIGC 标识展示、导出、人工复核、投诉、删除、积分返还、账号限制。日志必须包含任务 ID、用户 ID/组织 ID、规则版本、Prompt 版本、模型、风险等级、动作、时间、操作者和脱敏环境信息。

### 8.4 权限要求

| 角色 | 权限 |
|---|---|
| 普通用户 | 查看自己的授权、标识、风险提示、投诉状态 |
| 团队管理员 | 查看团队任务合规状态和投诉状态 |
| 客服 | 查看用户可见信息、提交补偿申请，不可修改风险规则 |
| 人工复核员 | 查看必要证据、做复核决策、要求补充材料 |
| 风控管理员 | 配置规则、查看风险看板、处理投诉 |
| 法务/合规负责人 | 查看高风险案件、规则版本、审计日志 |
| 超级管理员 | 全权限，但规则发布和高风险删除建议双人确认 |
| AIcoding Agent | 仅开发/测试环境权限，不得访问生产敏感数据 |

### 8.5 数据留存与删除

1. 授权、合规审核、AIGC 标识、人工复核、投诉和删除日志必须保留最小必要信息。
2. 用户删除任务后，业务资产和派生内容必须按 D17/D18 删除。
3. 投诉成立后，争议内容不得继续用于展示、导出、模板、样本或 Prompt 进化。
4. 未经明确授权，用户上传视频和业务信息不得用于训练模型。
5. 审计日志必须脱敏，不保留完整高风险内容。

1. 产品首发市场是否面向中国大陆用户；如涉及海外市场，需补充对应地区合规规则。
2. 是否需要履行算法备案、安全评估或相关上架审核材料准备。
3. AIGC 标识的最终文案、样式、位置和是否允许企业内部版本自定义。
4. 隐式标识在 PDF、Docx、Markdown、JSON、后续视频文件中的具体实现标准。
5. 用户协议、隐私政策、授权条款和投诉处理规则最终法务版本。
6. 用户上传素材是否允许用于模型训练；默认建议不允许，除非单独授权。
7. 权利人投诉入口是否需要公开页面、邮箱、工单系统或企业认证流程。
8. 投诉成立后的退款/补偿政策。
9. 高风险行业是否 MVP1 直接禁用，还是支持人工复核后有限开放。
10. 是否允许企业客户关闭显式标识但保留隐式标识和用户责任确认。
11. 平台规则适配优先级：抖音、快手、视频号、小红书、B站、TikTok 是否分批支持。
12. 人工复核团队初期由谁负责，是否需要双人复核。
13. 合规规则版本发布是否需要审批流。
14. 风控误拦后的用户补偿政策。
15. 投诉删除后的最小审计日志留存周期。
16. 高风险用户/组织的限制、封禁和申诉策略。
17. 视频生成能力进入 MVP3 后，是否单独补充视频水印、元数据和平台发布标识文档。
18. 生成内容用于商业广告投放时，是否需要额外广告法审核规则。
19. 与第三方模型供应商的数据传输、日志留存、训练使用限制是否签署补充协议。
20. 最终上线前是否由法务顾问、风控负责人和项目 Owner 联合签署发布门禁。

## 结语

D21 的交付标准不是“写了合规说明”，而是系统在真实用户使用时能够做到：

```text
用户知道边界
→ 系统确认授权
→ 输入先过预检
→ AI 输出受约束
→ 风险自动分级
→ 高风险能拦截
→ 中风险能重写
→ 不确定能转人工
→ 导出保留 AIGC 标识
→ 投诉可以处理和删除
→ 积分可以正确返还
→ 后台可以审计复盘
→ 上线可以被测试门禁拦住
```

只有这样，本项目才能从“爆款拆解工具”升级为真正可商业化、可交付、可持续迭代的 AI 短视频爆款增长引擎。

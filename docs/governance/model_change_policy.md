# 模型供应商/版本变更政策

> Authority: D11, D12, D19

---

## 触发条件

模型变更包括：供应商切换、模型版本升级、路由策略调整、降级策略变更。

## 必须记录

| 维度 | 旧值 | 新值 | 变化率 |
|------|------|------|--------|
| 成本（micro USD/call） | | | |
| 质量评分（Benchmark） | | | |
| 延迟（p50/p95/p99） | | | |
| 失败率 | | | |
| Token 消耗 | | | |
| JSON Schema 合法率 | | | |

## 必须执行

1. 在 staging 环境运行完整 Benchmark Suite
2. 对比成本（新模型不得使毛利为负）
3. 对比质量（不得低于旧模型 5% 以上）
4. 对比延迟（不得超过旧模型 2x）
5. 运行红队样本（风控不退化）
6. 灰度切流（10% → 50% → 100%）
7. 监控 24h 无异常

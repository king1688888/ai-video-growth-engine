# 计费规则变更政策

> Authority: D19

---

## 触发条件

计费变更包括：积分定价调整、免费额度变更、扣费规则变更、返还规则变更、套餐变更。

## 必须执行

| 步骤 | 说明 | 阻塞 |
|------|------|------|
| 1. 幂等测试 | 冻结/扣费/返还在并发下幂等 | 是 |
| 2. 失败返还测试 | 任务失败后积分正确返还 | 是 |
| 3. 余额不为负测试 | 任何路径下余额不为负 | 是 |
| 4. 毛利影响评估 | 新规则下毛利是否为正 | 否（但必须记录） |
| 5. 存量用户影响 | 已购买用户的权益是否受影响 | 是 |
| 6. 公告计划 | 价格变更需提前通知用户 | 是（涨价时） |

## PR 模板

```markdown
## 计费规则变更 PR

### 变更内容
- 旧规则: ___
- 新规则: ___

### 变更原因

### 幂等测试结果
- 并发冻结: PASS/FAIL
- 并发扣费: PASS/FAIL
- 并发返还: PASS/FAIL
- 余额不为负: PASS/FAIL

### 毛利影响
- 旧毛利率: ___%
- 新毛利率: ___%

### 存量用户影响
- 受影响用户数: ___
- 处理方案: ___

### 回滚方式
恢复旧计费配置 + 差额补偿。
```

# 风控阈值变更政策

> Authority: D13, D21

---

## 触发条件

风控变更包括：相似度阈值调整、风险等级映射变更、拦截规则增减、人工复核触发条件变更。

## 必须执行

| 步骤 | 说明 | 阻塞 |
|------|------|------|
| 1. 运行红队样本 | 所有 redteam_samples.json 必须通过 | 是 |
| 2. 计算误拦截率 | 合法内容被错误拦截的比例 | 是（< 5%） |
| 3. 计算漏放率 | 高风险内容未被拦截的比例 | 是（< 2%） |
| 4. 影响评估 | 对积分返还/人工复核工单量的影响 | 否 |
| 5. PR Review | 含红队测试结果 | 是 |
| 6. 灰度 | 新规则先对 10% 流量生效 | 是 |

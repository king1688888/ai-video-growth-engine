# AI 自媒体对标账号拆解、原创化生成与数据进化系统完整方案

> 文档版本：V1.0  
> 生成日期：2026-05-22  
> 适用对象：AI 自媒体软件创始人、产品负责人、研发负责人、增长负责人、Agent 自动化研发执行团队  
> 核心目标：将“对标账号拆解与复刻”升级为“爆款结构学习 + 原创化生成 + 数据驱动进化”的商业级 AI 短视频增长系统。

---

## 0. 一句话结论

这个产品方向值得做，但不能停留在“复制对标账号视频”的层面。真正可商业化、可规模化、可合规、可形成壁垒的方向应该是：

> **面向短视频创作者、企业 IP、内容团队和本地商家的 AI 爆款内容增长引擎：用户输入对标账号、爆款视频、账号 ID 或自有作品数据，系统通过多模态理解模型拆解爆款规律，提炼内容 DNA，生成适合用户行业、人设、产品和素材的原创脚本、分镜、提示词和视频草稿，并根据发布数据持续诊断、归因、优化和进化。**

产品的核心不是“让用户搬运爆款”，而是：

> **把别人的爆款规律转化成用户自己的原创内容生产能力。**

---

## 1. 原始方案复盘

### 1.1 用户最初的产品设想

用户希望做一款 AI 自媒体软件，主要能力包括：

1. 用户上传短视频平台对标账号链接或账号 ID。
2. 系统通过视觉理解模型，例如 Gemini Flash 2.5 等，自动拆解对标账号。
3. 用户可以选择：
   - 全部作品模仿；
   - 部分作品拆解模仿；
   - 根据发布时间、互动数据等条件筛选作品。
4. 系统对对标账号进行账号分析和视频拆解。
5. 通过视觉理解、多模态模型，将视频拆解为可以被 AIGC 生成模型使用的反推提示词。
6. 将提示词输入视频生成模型，例如 Seedance、Veo 等，生成对标账号爆款视频的复刻版本。
7. 用户可以加入自己的想法，例如“将视频里的 XX 替换成 XXX”，系统融合后生成新的组合提示词。
8. 如果对标视频超过 15 秒，则通过视频切片、生成、拼接完成长视频。
9. 增加批量生成能力。
10. 根据已有账号作品做提示词创新，生成老作品的创新版本、剧情迭代版本。
11. 后续跟踪发布数据，进行视频诊断、账号诊断、数据归因、再优化。
12. 根据数据反馈优化提示词，再生成、再发布，沉淀优质提示词，让数据越来越好。

### 1.2 方案中已经非常正确的部分

这个设想里有几个非常重要的正确判断：

#### 第一，用户痛点是真实的

短视频创作者真正痛苦的不是“不会打开剪辑软件”，而是：

- 不知道应该学谁；
- 不知道为什么别人能爆；
- 不知道如何拆爆款；
- 不知道如何把对标账号内容迁移到自己行业；
- 不知道如何批量稳定地产出；
- 不知道视频发出去后为什么表现不好；
- 不知道下一条应该怎么改。

这个产品正好切中了这些痛点。

#### 第二，对标账号是强需求入口

短视频从业者天然会问：

- 我的同行谁做得好？
- 我应该模仿哪个账号？
- 这个爆款视频为什么火？
- 我能不能把它改成我自己的版本？
- 我能不能批量复制它的成功规律？

所以“对标账号输入”是一个非常强的产品入口，比单纯“输入一句话生成视频”更贴近真实业务场景。

#### 第三，视频理解模型已经可以支撑原型

当前多模态模型已经可以处理视频理解、时间线分析、镜头描述、字幕识别、场景理解、结构化输出等任务。官方 Gemini API 文档也明确支持视频理解和结构化输出，这使“视频 → 内容拆解 → 结构化资产”成为可落地链路。

#### 第四，视频生成模型已经可以支撑草稿生产

Veo 3.1、Seedance 2.0、可灵、Runway、Pika、海螺等模型已经具备较强的文本生成视频、图生视频、参考图生成、视频风格控制、镜头控制、音视频联合生成能力。因此“提示词 → 视频草稿”的链路已经具备商业原型条件。

#### 第五，数据反馈闭环是长期壁垒

如果产品只做到“生成视频”，很容易被视频生成模型平台替代。  
但如果产品能做到：

> 对标拆解 → 创意重构 → 视频生成 → 发布数据回填 → 表现归因 → 提示词进化 → 再生成

它就会从工具变成增长系统，这才是真正有长期价值的方向。

## 2. 方案最需要升级的核心判断

### 2.1 不要把产品定义成“复刻工具”

“复刻”是用户能听懂的卖点，但也是最大风险点。

如果产品直接帮助用户复制他人账号的：

- 脚本；
- 台词；
- 分镜；
- 人物形象；
- 声音；
- 画面风格；
- 商标；
- 封面；
- 配乐；
- 特定原创剧情；
- 特定广告创意；

就会面临版权、肖像权、商标权、不正当竞争、平台反搬运、账号限流等风险。

更合理的产品定义是：

> **爆款结构学习与原创化内容生成系统。**

也就是说，系统应该学习：

- 爆款选题逻辑；
- 钩子设计；
- 情绪曲线；
- 镜头节奏；
- 内容结构；
- 转化路径；
- 评论诱导方式；
- 账号栏目结构；
- 用户心理触发点；

但不应该直接搬运：

- 原始视频素材；
- 原文案；
- 原字幕；
- 原音乐；
- 原人物；
- 原 Logo；
- 原品牌元素；
- 原视频的可识别表达。

### 2.2 产品宣传语建议调整

不建议使用：

> 1:1 复刻对标账号爆款视频。

建议改为：

> 输入对标账号，自动拆解爆款规律，生成适合你账号的原创爆款候选内容。

或者：

> 拆解同行爆款内容 DNA，批量生成你自己账号可发布的原创脚本、分镜和视频草稿。

或者：

> 不是搬运爆款，而是把爆款的底层结构迁移到你的行业、人设和产品里。

## 3. 推荐产品定位

### 3.1 产品名称方向

可以考虑以下命名方向：

1. 爆款 DNA
2. 对标增长引擎
3. AI 短视频增长官
4. 爆款工厂
5. 创作者增长 Agent
6. 对标账号拆解助手
7. 内容 DNA 引擎
8. AI 爆款导演
9. 短视频增长 Copilot
10. AI 账号增长操作系统

### 3.2 推荐定位

> **面向短视频创作者、企业 IP、内容团队、本地商家和带货账号的 AI 对标账号增长系统。**

### 3.3 推荐一句话价值

> 用户输入对标账号或爆款视频，系统自动拆解爆款规律，生成适合用户行业、人设、产品和素材的原创脚本、分镜、提示词与视频草稿，并根据发布数据持续优化内容策略。

### 3.4 不建议的定位

不建议定位为：

- AI 搬运工具；
- 爆款复制器；
- 对标账号 1:1 克隆器；
- 视频洗稿工具；
- 短视频自动搬运系统。

这些定位短期刺激，但长期风险高，不利于商业化、融资、企业客户采购和平台合作。

## 4. 目标用户与高价值场景

### 4.1 第一优先级用户

#### 1. 企业 IP 和老板 IP

痛点：

- 不知道拍什么；
- 不知道如何借鉴同行；
- 内容团队效率低；
- 每周都需要稳定产出；
- 需要获客和信任建立。

适配价值：

- 账号对标；
- 行业选题；
- 脚本批量生成；
- 视频草稿生成；
- 数据诊断。

付费能力：高。

#### 2. 本地生活商家

例如：

- 餐饮；
- 医美；
- 教培；
- 健身；
- 房产；
- 家装；
- 摄影；
- 汽修；
- 宠物；
- 亲子。

痛点：

- 不会做短视频；
- 需要模仿同行爆款；
- 缺乏内容策划；
- 内容更新频率低；
- 强依赖本地获客。

适配价值：

- 对标本地同行；
- 批量生成探店/案例/优惠/老板 IP 内容；
- 自动形成发布计划。

付费能力：中高。

#### 3. 知识 IP / 课程培训

痛点：

- 需要大量选题；
- 需要强钩子；
- 需要持续涨粉和转化；
- 需要脚本和口播内容。

适配价值：

- 爆款口播拆解；
- 观点重构；
- 脚本生成；
- 标题封面生成；
- 数据诊断。

付费能力：中高。

#### 4. MCN / 内容工作室

痛点：

- 多账号运营；
- 批量内容生产；
- 需要对标多个账号；
- 人工拆解成本高；
- 需要 SOP 化生产。

适配价值：

- 多账号分析；
- 批量生成；
- 团队协作；
- 审核流程；
- 数据看板。

付费能力：高。

### 4.2 不建议第一阶段优先做的用户

以下用户或场景第一阶段不建议优先做：

1. 影视混剪号  
   版权风险较高。

2. 明星娱乐号  
   肖像、版权、热点时效和平台风控复杂。

3. 搬运号  
   商业价值和合规风险不匹配。

4. 纯二创鬼畜号  
   审核与版权不确定性较高。

5. 高度依赖真人仿脸、仿声的账号  
   肖像权、声音权、深度合成合规风险高。

6. 强医疗、金融、法律建议类内容  
   需要更重的专业审核和风控。

## 5. 产品主流程设计

### 5.1 标准用户流程

完整流程建议如下：

1. 用户注册登录。
2. 用户填写账号基础画像：
   - 行业；
   - 产品/服务；
   - 目标用户；
   - 内容目标；
   - 是否真人出镜；
   - 是否有素材；
   - 账号阶段；
   - 平台选择。
3. 用户输入对标账号链接、账号 ID、作品链接，或上传视频文件。
4. 系统进行数据接入与合规校验。
5. 系统判断对标账号是否值得学习。
6. 系统筛选高价值爆款作品。
7. 用户选择要拆解的作品。
8. 系统进行视频理解：
   - 抽帧；
   - OCR；
   - ASR；
   - 镜头切分；
   - 多模态理解；
   - 时间线分析。
9. 系统输出内容 DNA：
   - 选题；
   - 钩子；
   - 脚本；
   - 分镜；
   - 情绪曲线；
   - 镜头节奏；
   - 转化路径。
10. 系统输出可复用部分和不可复用部分。
11. 系统进行相似度风险和版权风险判断。
12. 系统根据用户行业、人设、产品和素材进行原创化重构。
13. 系统生成多个版本：
   - 脚本版；
   - 分镜版；
   - 口播版；
   - 图文版；
   - 视频生成 Prompt 版；
   - 批量裂变版。
14. 用户选择版本并修改需求。
15. 系统生成创意 IR。
16. 模型路由器选择合适的视频生成模型。
17. 视频导演 Agent 拆分分镜并生成视频片段。
18. 系统进行多模态质检。
19. 不合格片段局部重生。
20. 系统拼接成片、生成字幕、音频、封面、标题和发布文案。
21. 用户下载或发布。
22. 用户回填发布数据。
23. 系统进行数据诊断和归因。
24. 系统优化下一轮提示词。
25. 沉淀用户专属爆款模板和提示词库。

### 5.2 极简 MVP 流程

第一版不建议做完所有功能，建议先做：

1. 上传一条视频。
2. 系统自动拆解。
3. 输出爆款分析报告。
4. 输出可复用模板。
5. 输出 5 个原创改写脚本。
6. 输出 3 个视频生成提示词。
7. 用户复制提示词去视频模型生成。
8. 用户反馈生成质量。

这个版本能最快验证：

- 用户是否需要；
- 拆解质量是否足够；
- 用户是否愿意付费；
- Prompt 是否真的有用。

## 6. 核心模块设计

## 6.1 用户画像模块

### 目标

让系统知道“用户是谁、账号要做什么、内容服务谁、最终要转化什么”。

### 必填字段

| 字段 | 说明 |
|---|---|
| 行业 | 教培、本地生活、知识 IP、企业服务、电商等 |
| 账号阶段 | 冷启动、起量期、稳定期、商业化期、衰退期 |
| 内容目标 | 涨粉、获客、带货、私域、品牌曝光 |
| 目标用户 | 年龄、性别、城市、需求、痛点 |
| 产品/服务 | 用户要推广的产品或服务 |
| 人设定位 | 专家型、老板型、朋友型、测评型、剧情型 |
| 出镜方式 | 真人出镜、AI 人物、素材混剪、图文视频 |
| 可用素材 | 产品图、门店视频、客户案例、老板口播等 |
| 禁用内容 | 禁止出现的词、画面、承诺、风格 |
| 平台 | 抖音、快手、视频号、小红书、TikTok 等 |

### 输出

- 用户内容策略画像；
- 用户可复制内容类型；
- 用户适合的爆款模板；
- 用户不适合的内容方向。

## 6.2 对标账号价值判断模块

### 为什么需要这个模块

不是所有爆款账号都值得学。  
很多账号能火，是因为拥有普通用户无法复制的资源：

- 明星身份；
- 强供应链；
- 强资金投放；
- 强剧情团队；
- 平台流量扶持；
- 历史粉丝积累；
- 线下门店数量；
- 稀缺资源；
- 争议人物；
- 特殊事件。

如果用户盲目对标这些账号，结果大概率失败。

### 核心评分维度

| 维度 | 说明 |
|---|---|
| 行业匹配度 | 是否与用户行业/产品/目标用户匹配 |
| 结构可复制性 | 内容是否有稳定模板和可迁移结构 |
| 资源依赖度 | 是否依赖明星、预算、团队、供应链、线下资源 |
| 风险程度 | 是否涉及版权、肖像、商标、敏感内容 |
| 新手友好度 | 普通创作者是否能模仿 |
| 商业转化潜力 | 是否能带来私信、留资、下单、咨询 |
| 内容稳定性 | 是否长期持续输出，而不是偶然爆款 |
| 账号阶段差异 | 用户当前阶段是否适合学习该账号 |

### 输出结果

- 对标账号可学习评分；
- 推荐学习内容；
- 不建议学习内容；
- 风险提醒；
- 替代对标账号建议；
- 最适合迁移的爆款模板。

## 6.3 爆款作品筛选模块

### 不建议只看绝对数据

不能只看：

- 点赞数；
- 评论数；
- 转发数；
- 播放量。

因为大号的普通视频数据也可能很高，小号的视频只要明显超过自身基准，就更有研究价值。

### 推荐使用相对爆款指标

核心指标：

> 相对爆款倍率 = 单条作品表现 / 该账号历史平均表现

例如：

- 一个千万粉账号 10 万点赞，可能只是正常水平；
- 一个 1 万粉账号 1 万点赞，可能是极具参考价值的异常爆款。

### 推荐筛选指标

| 指标 | 价值 |
|---|---|
| 相对播放倍率 | 判断是否超过账号基准 |
| 相对点赞倍率 | 判断内容是否触发情绪价值 |
| 评论密度 | 判断是否引发讨论 |
| 收藏/点赞比 | 判断实用价值 |
| 转发/点赞比 | 判断传播价值 |
| 发布时间 | 判断是否是近期有效内容 |
| 单位时间增长 | 判断早期加速能力 |
| 视频时长 | 判断适合口播、剧情、混剪还是短平快 |
| 选题类型 | 判断是否可系列化 |
| 是否热点驱动 | 判断是否可复用 |
| 是否依赖特殊素材 | 判断是否可迁移 |

### 输出

- 值得拆解 Top N 作品；
- 不适合拆解作品；
- 偶然爆款识别；
- 可长期复用爆款识别；
- 可批量裂变作品识别。

## 6.4 视频深度理解模块

### 输入

- 视频文件；
- 视频链接；
- 账号作品列表；
- 用户上传的本地素材；
- 截图；
- 字幕文件；
- 评论数据；
- 互动数据。

### 处理步骤

1. 视频元数据解析：
   - 时长；
   - 分辨率；
   - 比例；
   - 发布时间；
   - 标题；
   - 标签；
   - 互动数据。
2. 抽帧：
   - 固定时间抽帧；
   - 镜头变化抽帧；
   - 关键帧抽取。
3. OCR：
   - 屏幕字幕；
   - 画面文字；

## 6.6 创意中间层 IR 模块

### 为什么必须有 IR

不要直接从视频拆解结果生成模型 Prompt。  
因为不同视频生成模型的能力边界不同：

- 有些模型更适合短视频；
- 有些模型更适合人物一致性；
- 有些模型更适合镜头运动；
- 有些模型支持原生音频；
- 有些模型支持参考图；
- 有些模型支持视频参考；
- 有些模型生成速度快但质量一般；
- 有些模型质量高但成本高。

所以需要一个模型无关的中间层：

> 内容 DNA → 创意 IR → 模型专用 Prompt

### 创意 IR 示例

```json
{
  "creative_goal": "涨粉/获客/带货/种草/私域引流",
  "platform": "抖音/快手/视频号/小红书/TikTok",
  "target_audience": "目标用户",
  "account_persona": "账号人设",
  "product_or_service": "产品/服务",
  "core_message": "核心表达",
  "hook": "前3秒钩子",
  "story_arc": "剧情结构",
  "visual_style": "视觉风格",
  "originality_strategy": "原创化策略",
  "similarity_control": "避免与参考视频过度相似的控制策略",
  "shots": [
    {
      "duration": 4,
      "scene": "场景",
      "subject": "主体",
      "action": "动作",
      "camera": "镜头语言",
      "subtitle": "字幕",
      "audio": "音频",
      "purpose": "镜头作用"
    }
  ],
  "model_prompt_targets": {
    "veo": "Veo 专用提示词",
    "seedance": "Seedance 专用提示词",
    "kling": "可灵专用提示词",
    "runway": "Runway 专用提示词"
  }
}
```

### IR 的好处

1. 降低模型更换成本。
2. 提高生成稳定性。
3. 方便多模型路由。
4. 方便版本管理。
5. 方便数据回溯。
6. 方便提示词进化。
7. 方便合规审查。
8. 方便研发测试。

## 6.7 原创化重构模块

### 产品必须提供的原创化模式

| 模式 | 说明 |
|---|---|
| 结构复用 | 学习爆款结构，但完全重写表达 |
| 行业迁移 | 将爆款模板迁移到用户行业 |
| 人设替换 | 替换为用户自己的身份、语气、口吻 |
| 场景替换 | 替换成用户真实场景 |
| 产品替换 | 融入用户自己的产品或服务 |
| 剧情升级 | 加入冲突、反转、悬念或新的剧情线 |
| 观点创新 | 加入新的洞察、判断、案例 |
| 系列扩展 | 从一条爆款裂变出连续 5-20 条 |
| 风格变化 | 从严肃改成轻松，从口播改成剧情等 |
| 平台适配 | 同一主题适配不同平台内容风格 |

### 原创化强度

建议设置 4 档：

1. **低强度结构参考**  
   适合用户想快速理解爆款结构，但不直接生成成片。

2. **中强度行业改写**  
   保留内容骨架，替换行业、痛点、产品和表达。

3. **高强度原创重构**  
   只保留底层心理触发点，重新设计脚本、场景和镜头。

4. **强原创裂变**  
   从爆款中提炼规律，生成一组全新选题和内容系列。

### 系统默认策略

默认不应该输出“高度相似版本”，而应该输出“原创化重构版本”。

## 6.8 视频导演 Agent 模块

### 为什么需要视频导演 Agent

超过 15 秒的视频生成不能只是简单拼接。  
否则会出现：

- 人物前后不一致；
- 场景跳变；
- 光线不统一；
- 音频断裂；
- 字幕风格不统一；
- 剧情不连贯；
- 转场生硬；
- 生成片段像多个独立视频拼在一起。

### 视频导演 Agent 的职责

1. 将完整脚本拆分为多个分镜。
2. 为每个分镜设定时长。
3. 建立统一角色卡。
4. 建立统一场景卡。
5. 建立统一视觉风格卡。
6. 建立统一音频风格卡。
7. 为每个分镜生成模型专用 Prompt。
8. 控制片段之间的衔接。
9. 生成后进行多模态质检。
10. 对失败片段进行局部重生。
11. 进行视频拼接、字幕、BGM、封面合成。
12. 输出成片和发布物料。

### 推荐生成链路

> 脚本 → 分镜 → 角色卡 → 场景卡 → 风格卡 → 镜头卡 → 单段生成 → 多模态质检 → 局部重生 → 拼接 → 字幕 → 音频 → 封面 → 导出

## 6.9 多模型路由模块

### 为什么不能绑定单一模型

视频生成模型更新很快。  
今天最好的模型，几个月后可能就不是最优选择。  
商业级产品必须支持模型替换和多模型路由。

### 模型路由维度

| 维度 | 说明 |
|---|---|
| 成本 | 单秒生成成本、失败重试成本 |
| 速度 | 生成等待时间 |
| 质量 | 画面质量、物理合理性、镜头稳定性 |
| 时长 | 单次生成最长时长 |
| 比例 | 是否支持 9:16、16:9、1:1 |
| 音频 | 是否支持原生音频、口型、音效 |
| 参考能力 | 是否支持图像、视频、音频参考 |
| 人物一致性 | 是否能保持角色一致 |
| 商业稳定性 | API 稳定性、并发、限流 |
| 合规能力 | 安全过滤、版权保护、日志能力 |

### 推荐任务分配

| 任务 | 推荐能力 |
|---|---|
| 视频理解 | Gemini 2.5 Flash/Pro 类多模态视频理解模型 |
| 脚本分析 | 高推理文本模型 |
| 分镜生成 | 文本模型 + 多模态理解模型 |
| 视频草稿 | 低成本快速视频模型 |
| 高质量成片 | Veo、Seedance、可灵等高质量模型 |
| 参考式生成 | 支持图像/视频/音频参考的模型 |
| 质检 | 多模态评估模型 |
| 合规审核 | 文本、图像、音视频安全模型 |

## 6.10 质量评估模块

### 为什么需要质检

商业级产品不能把模型生成结果直接交给用户。  
视频生成存在大量不稳定因素：

- 人脸变形；
- 手指异常；
- 文字乱码；
- 动作不自然；
- 镜头跑偏；
- 字幕遮挡；
- 音频不同步；
- 人物前后不一致；
- 风格失控；
- 内容违规。

### 质检维度

| 维度 | 检测内容 |
|---|---|
| 画面质量 | 清晰度、畸变、穿帮、模糊、闪烁 |
| 人物一致性 | 脸、发型、服装、体型是否一致 |
| 场景一致性 | 背景、光线、空间关系是否一致 |
| 动作合理性 | 动作是否自然、是否有物理错误 |
| 字幕质量 | 是否错字、遮挡、不同步、样式错乱 |
| 音频质量 | 是否断裂、杂音、口型不匹配 |
| 节奏质量 | 是否拖沓、重点不清、转场突兀 |
| 爆款潜力 | 钩子、节奏、情绪、讨论点、转化点 |
| 原创度 | 是否与参考视频过度相似 |
| 合规风险 | 版权、肖像、品牌、低俗、虚假宣传等 |

### 输出

- 成片质量评分；
- 风险评分；
- 优化建议；
- 是否建议重生；
- 建议重生的具体片段；
- 一键局部重生按钮。

## 6.11 相似度风控模块

### 必须检测的相似度

| 类型 | 检测对象 |
|---|---|
| 文案相似度 | 台词、字幕、标题、封面文案 |
| 分镜相似度 | 镜头顺序、转场方式、节奏结构 |
| 画面相似度 | 场景、主体、构图、色调 |
| 人物相似度 | 脸、声音、服装、标志性动作 |
| 音乐相似度 | BGM、音效、节奏 |
| 品牌相似度 | Logo、商标、包装、店铺元素 |
| 剧情相似度 | 情节走向、关键桥段、反转结构 |
| 封面相似度 | 排版、标题、人物、色彩 |

### 风险分级

| 风险等级 | 处理方式 |
|---|---|
| 低风险 | 可正常生成 |
| 中风险 | 提醒用户进行原创化改写 |
| 高风险 | 强制重构场景、人设、文案、镜头 |
| 极高风险 | 禁止生成或要求用户提供授权证明 |

### 推荐产品提示

当相似度过高时，系统提示：

> 当前内容与参考视频相似度较高，可能存在版权、平台搬运或账号限流风险。建议切换为“行业迁移”或“强原创重构”模式，替换场景、人设、文案和镜头结构后再生成。

## 6.12 数据反馈与归因模块

### 为什么这是长期壁垒

视频生成只是一次性交付。  
数据反馈才能让系统越用越准。

如果系统能知道：

- 哪种选题适合用户；
- 哪种开头用户账号更容易起量；
- 哪种封面点击率更高；
- 哪种脚本完播率更高；
- 哪种 CTA 转化更好；

就能形成用户专属增长模型。

### 指标分层

| 数据层 | 指标 | 归因方向 |
|---|---|---|
| 曝光层 | 展现量、推荐量、搜索流量 | 选题、标签、账号权重 |
| 点击层 | 封面点击率、标题点击率 | 封面、标题、第一眼吸引力 |
| 留存层 | 3 秒留存、5 秒留存 | 开头钩子 |
| 完播层 | 平均播放时长、完播率、重播率 | 节奏、剧情、信息密度 |
| 互动层 | 点赞、评论、收藏、转发 | 情绪价值、实用价值、讨论点 |
| 转粉层 | 关注率、主页访问率 | 人设、信任感、系列感 |
| 转化层 | 私信、留资、商品点击、成交 | CTA、产品表达、信任链路 |

### 归因示例

| 表现 | 可能原因 |
|---|---|
| 播放低 | 选题弱、标签错、账号权重低、发布时间不佳 |
| 点击低 | 封面弱、标题弱、第一眼利益点不清 |
| 3 秒留存低 | 开头钩子弱、废话多、画面不吸引 |
| 完播低 | 节奏拖、信息密度低、剧情无反转 |
| 点赞低 | 情绪价值不足、观点不鲜明 |
| 评论低 | 没有争议点、提问点、互动引导 |
| 收藏高但转粉低 | 实用但人设弱 |
| 评论高但转化低 | 讨论强但商业承接弱 |
| 转化低 | 信任链路弱、CTA 不明确、产品价值不清 |

## 10. 合规与风控设计

### 10.1 必须坚持的原则

1. 不帮助用户直接搬运他人内容。
2. 不克隆他人声音、肖像和身份。
3. 不复用原视频素材、台词、字幕、配乐和商标元素。
4. 不绕过平台限制进行非法爬取。
5. 不生成误导性、虚假宣传、侵权或违法内容。
6. 对 AI 生成内容进行必要标识。
7. 保存用户授权、生成日志、模型调用日志和审核记录。
8. 对高风险行业进行额外审核。

### 10.2 数据获取合规

推荐数据来源优先级：

1. 用户主动上传并确认有权使用的素材。
2. 用户授权接入的自有账号数据。
3. 平台允许公开访问的公开信息。
4. 合法第三方数据服务。
5. 用户手动导入的数据表格。

不建议依赖：

- 未授权爬虫；
- 绕过平台限制下载；
- 大规模抓取他人作品；
- 未经授权复用视频素材；
- 灰产数据接口。

### 10.3 AIGC 标识

如果产品面向中国境内公众提供文本、图片、音频、视频等生成式 AI 服务，需要关注《生成式人工智能服务管理暂行办法》。同时，《人工智能生成合成内容标识办法》和 GB 45438-2025《网络安全技术 人工智能生成合成内容标识方法》已经对生成合成内容标识提出要求。

产品应预留：

- 显式标识；
- 隐式标识；
- 文件元数据标识；
- 水印机制；
- 用户提示；
- 生成日志；
- 内容来源记录；
- 删除与申诉机制。

### 10.4 高风险内容类别

需重点风控：

- 医疗疗效承诺；
- 金融收益承诺；
- 法律结论性建议；
- 虚假广告；
- 未成年人敏感内容；
- 深度伪造人脸；
- 仿冒公众人物；
- 商标/品牌滥用；
- 低俗擦边；
- 政治敏感；
- 违法违规营销。

### 10.5 产品内置风控动作

| 风险 | 动作 |
|---|---|
| 文案过度相似 | 自动重写 |
| 镜头过度相似 | 强制更换分镜 |
| 人物相似 | 禁止生成或要求授权 |
| 声音相似 | 禁止仿声 |
| 品牌元素 | 自动打码或提示删除 |
| 医疗金融承诺 | 加强审核，提示风险 |
| 平台搬运风险 | 强制原创化重构 |
| 高风险账号对标 | 降低推荐权重或禁止 |

## 18. 关键风险与应对方案

### 风险 1：数据源不稳定

应对：

- 优先用户授权和主动上传；
- 支持手动导入；
- 不依赖单一第三方接口；
- 保留多数据源；
- 降低爬虫依赖。

### 风险 2：生成质量不稳定

应对：

- 先做脚本和分镜；
- 视频生成先作为草稿；
- 加入质检；
- 支持局部重生；
- 支持用户编辑；
- 多模型路由。

### 风险 3：成本过高

应对：

- 草稿模式；
- 高清模式；
- 积分系统；
- 成本预估；
- 重试限制；
- 片段级重生；
- 不合格前置拦截。

### 风险 4：版权与平台风险

应对：

- 原创化重构；
- 相似度检测；
- 不直接复制；
- 不提供搬运导向；
- 保存授权记录；
- AIGC 标识；
- 投诉处理机制。

### 风险 5：用户冷启动体验差

应对：

- 提供行业模板；
- 提供样例账号；
- 提供一键 Demo；
- 提供新手推荐；
- 先让用户拿到脚本和选题，不强迫生成视频。

### 风险 6：产品太复杂

应对：

- 分阶段 MVP；
- 先单视频拆解；
- 再账号拆解；
- 再视频生成；
- 再数据闭环；
- 每个模块独立开发、测试、上线。

## 23. 最终建议

### 23.1 最重要的 5 个建议

如果资源有限，只做最关键的 5 件事：

1. **先做内容 DNA Schema**  
   这是所有自动化拆解、创意生成、数据归因的基础。

2. **先验证拆解报告付费**  
   不要一开始重投入视频生成，先证明用户愿意为“拆解 + 脚本 + 提示词”付费。

3. **从“复刻”升级为“原创化迁移”**  
   这是合规、安全、长期商业化的关键。

4. **建立相似度与原创度风控**  
   这是避免侵权、搬运、平台限流和商业风险的底线。

5. **把数据反馈做成长期壁垒**  
   让产品从一次性工具变成用户持续依赖的增长系统。

### 23.2 推荐第一版产品形态

第一版最建议做成：

> **AI 爆款视频拆解与原创脚本生成工具。**

用户上传一个对标视频，系统输出：

- 爆款原因；
- 内容结构；
- 分镜拆解；
- 镜头节奏；
- 情绪曲线；
- 可复用模板；
- 不可复制风险；
- 5 个原创改写脚本；
- 10 个标题；
- 3 个封面建议；
- 3 个视频生成 Prompt；
- 1 份可下载报告。

这个版本最容易做、最容易卖、最容易验证。

### 23.3 第二版产品形态

第二版升级为：

> **对标账号分析与批量内容计划工具。**

用户输入对标账号，系统输出：

- 账号定位；
- 栏目拆解；
- 爆款作品筛选；
- 可复制性评分；
- 选题矩阵；
- 一周内容计划；
- 批量脚本；
- Prompt 包。

### 23.4 第三版产品形态

第三版升级为：

> **AI 视频生成与数据进化系统。**

用户可以：

- 选择脚本；
- 生成分镜；
- 调用视频模型；
- 拼接成片；
- 发布；
- 回填数据；
- 获得诊断；
- 优化下一轮 Prompt。

## 24. 最终产品愿景

最终产品应该帮助用户完成这件事：

> 不再靠感觉做内容，而是通过 AI 持续学习同行爆款规律，结合自己的行业、人设、产品和数据反馈，形成可复制、可迭代、可增长的原创短视频生产系统。

你的产品长期价值不是“生成一个视频”，而是：

> **让用户的账号越来越懂自己该怎么做内容。**

这也是它区别于普通视频生成工具、剪辑工具、脚本工具和数据分析工具的地方。
